# triema-masker

Локальный мультиагентный обезличиватель тендерных документов (PDF/DOCX/XLSX).
Хакатон, заказчик — АО «Триема». Постановка: `docs/BRIEF.md`.

## Быстрый старт

```bash
make install     # venv на python 3.14 + зависимости
make gate        # ворота: линт, типы, тесты, метрики
```

## Структура

| Файл | Зачем |
|---|---|
| `AGENTS.md` | правила для агентов, инварианты, определение готовности |
| `ARCHITECTURE.md` | пайплайн, контракты, почему детекция трёхслойная |
| `TASKS.md` | задачи с критериями приёмки, по блокам |
| `docs/BRIEF.md` | постановка заказчика и её отображение в проверки |
| `docs/ECONOMICS.md` | три ресурса, тарифы, какая модель под какую задачу |
| `scripts/gate.sh` | единственные ворота проекта |
| `spikes/` | доказательства работоспособности рискованных мест |

## Что уже доказано запуском

- **PDF-редактирование настоящее.** `spikes/pdf_redact_spike.py` — текст
  вырезается из потока содержимого, его нет ни в текстовом слое, ни в байтах
  файла; маркер вписан, подсветка есть, метаданные зачищены.
- **Русский NER работает офлайн.** Natasha на CPU достаёт `ООО «Ромашка» → ORG`,
  `Иванов Иван Иванович → PER` без сети и без GPU.
- **Контрольные суммы реквизитов.** ИНН, ОГРН, СНИЛС, БИК, счёт —
  `src/masker/detect/checksums.py`, 16 тестов, включая заведомо битые значения.
- **Пауза на уточняющих вопросах.** `spikes/langgraph_pipeline_spike.py` —
  граф встаёт, отдаёт вопросы одной пачкой, критичные реквизиты человеку не
  выносит, возобновляется после пересоздания объекта графа (состояние в sqlite).
- **Ворота умеют не пройти.** `tests/masker/test_gate_selftest.py`.

## Агенты

Три роли, одинаковые в Claude Code и в Codex: оркестратор проектирует и пишет
план, кодер пишет код и тесты по этому плану, дешёвый исполнитель гоняет
команды и возвращает факты.

| Роль | Claude Code | Codex | Права |
|---|---|---|---|
| оркестратор | `opus` | `gpt-5.5`, xhigh | только чтение |
| кодер | `sonnet` | `gpt-5.3-codex`, high | запись в проект |
| исполнитель | `haiku` | `gpt-5.4-mini`, low | запись в проект |

Оркестратору права на запись не выданы намеренно: он не должен править код,
и песочница enforce-ит это надёжнее, чем просьба в промпте.

```bash
./scripts/codex.sh                # обычная сессия, gpt-5.5
./scripts/codex.sh -p runner      # дешёвый исполнитель
./scripts/codex.sh -p coder       # кодер

./scripts/dsh.sh                  # веб-интерфейс dsh на 3080
./scripts/dsh.sh --dump-config    # собранное дерево плагинов
```

Обёртки переключают `CODEX_HOME` и `DSH_HOME` на каталоги в репозитории —
роли, профили и патч-слой лежат под контролем версий и одинаковы у всей
команды. Ключи не копируются, а берутся симлинками из `~/.codex/auth.json`
и `~/.dsh/.credentials.yaml`. В Claude Code роли подхватываются сами
из `.claude/agents/`.

**dsh умеет вызывать Codex и Claude Code как подагентов.** Выберите в сессии
пресет **Триема** — в нём включены инструменты `subagent_codex` и
`subagent_claude_code` (в стандартном пресете они выключены). Codex-подагент
получает `CODEX_HOME=.codex/`, то есть те же роли, что и ручной запуск.
Провайдер запускает свою закреплённую обёртку `@openai/codex` 0.147.0,
хостовый бинарь не используется.

## Стек

Всё локальное и лёгкое: PyMuPDF, python-docx, openpyxl, Natasha, tesseract
(`rus` уже установлен). LLM — только на роли сторон и спорные случаи,
за интерфейсом `LLMProvider`. Движок целиком собран на LangGraph: узлы,
состояние, чекпойнты и пауза на уточняющих вопросах.

## Проверка профилей через OpenRouter

`masker.llm.yaml` содержит безопасную конфигурацию по умолчанию. Секрет в него
не записывается: перед запуском передайте ключ окружением. Команда отправляет
в OpenRouter найденные исходные PII и контекстные фрагменты документа, поэтому
явное подтверждение `--allow-remote-pii` обязательно.

```bash
export OPENROUTER_API_KEY='...'
.venv/bin/masker fixtures/labeled/contract_08_roles.docx \
  --out out/openrouter-check \
  --profile \
  --llm-config masker.llm.yaml \
  --allow-remote-pii
```

В `out/openrouter-check/contract_08_roles/report.json` появится блок
`profile_judge`: профили, роль, число вызовов модели, диагностика, вердикты и
вопросы. `preview.docx` по-прежнему содержит исходный текст и не предназначен
для передачи наружу. Живой smoke-тест доступен отдельно: `pytest -m e2e`.
