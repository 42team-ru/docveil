## Непокрытые требования — намеренно не скрыты

Форматы DOCX и XLSX не собраны: доступные официальные вложения ЕИС в этих
форматах в отобранных карточках оказались **проектами**, а не заключёнными
договорами. Их не подменяли реальными документами. PDF с текстовым слоем —
20; подтверждённый PDF-скан — только один (`hse-2013-contract-157.pdf`: 0
встроенных шрифтов, `pdftotext` даёт 9 байтов). Поэтому требование «минимум
3 скана» не выполнено.

Ни одного договора между организацией и обычным физлицом не найдено без
выхода за допустимый круг раскрытий. Аренда также не представлена. В выборке
есть четыре 223-ФЗ договора, но семейство контрактов ЕСПД повторяется у
нескольких разных заказчиков и не должно считаться независимым покрытием
семантики. Все 21 документа — PDF; это корпус начального среза, а не
закрытие полного матричного покрытия.

Карточки не выдают себя за данные реестра ЕИС: ни для одного файла из этого
среза не удалось получить JSON карточки реестра контрактов `zakupki.gov.ru`
с достаточной стабильностью. Поэтому в каждой локальной карточке явно стоит
`source_card_status`; она содержит проверяемую исходную ссылку, контрольную
сумму и полный текст опубликованного файла, но не выдуманные поля заказчика
или поставщика.
