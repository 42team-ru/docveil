# Постановка задачи (от заказчика)

**Заказчик:** АО «Триема», ИНН 3662103003.
Оптовая торговля электронными компонентами, деталями и запчастями.
**Контакт:** Андрей, 89103475107.

**Цель:** легковесный мультиагентный AI-помощник для автоматического
обезличивания конфиденциальных данных в тендерных документах (договоры,
финансовые отчёты, коммерческие предложения) произвольных форматов
(PDF, Word, Excel). Работает локально, с минимальными требованиями к ресурсам,
высокая скорость, на выходе документ с визуальной подсветкой всех изменений
для последующей ручной валидации.

**Функции:**

1. Принимает файл (PDF/DOCX/XLSX) и список типов данных для удаления.
2. Анализирует документ — извлекает текст и структуру (таблицы сохраняет),
   определяет, кто поставщик, а кто покупатель (если указано).
3. Находит фрагменты по заданным типам, заменяет на маскировочные маркеры,
   сохраняя форматирование.
4. Проверяет полноту — если данных не хватает, задаёт уточняющие вопросы.
5. Выдаёт обезличенный документ в исходном формате с подсветкой каждого
   изменения плюс отдельный отчёт (перечень заменённых фрагментов).
6. Позволяет легко сменить модель: вызов ИИ вынесен в отдельный слой, замена
   GigaChat на локальную модель не требует правки основной логики.

**Со звёздочкой:** поддержка сканированных PDF — распознавание через OCR
и применение всех функций маскировки к распознанному содержанию, с сохранением
в итоговом документе и текста, и визуальной подсветки.

**Данные:** синтетические и реальные тендерные документы (договоры, счета,
акты) в PDF/DOCX/XLSX, размеченные вручную (правильные сущности и роли).

**Ожидаемый результат:** рабочий локальный прототип, который по загруженному
файлу и списку типов находит и маскирует сущности, возвращая обезличенный
документ с подсветкой изменений.

Каждый пункт превращён в проверяемое условие:

| Пункт                        | Где проверяется                                     |

| 2, «таблицы сохраняет»       | инвариант «структура цела» в `AGENTS.md`            |
| 2, роли сторон               | T3.2, метрика ≥ 90% на корпусе                      |
| 3, «сохраняя форматирование» | T1.5, разрезание run вместо перезаписи абзаца       |
| 4, уточняющие вопросы        | T1.6, `MaskResult.questions`                        |
