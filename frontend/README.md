# frontend

Веб-интерфейс обезличивателя. Пока — только каркас каталога: стек и сборка
будут добавлены отдельной задачей.

## Что здесь появится

- SPA под REST API бэкенда (`../backend`, FastAPI, префикс `/api`).
- Экраны: загрузка документа + выбор типов данных → прогресс прогона →
  пауза на уточняющих вопросах графа (`ask_human`) → выдача двух файлов
  (чёрный и подсвеченный) и отчёта о заменах.

## Как связано с бэкендом

| | |
|---|---|
| API | `http://localhost:8000/api` (см. `../backend`, `make api` из корня) |
| Аутентификация | JWT, refresh-токен в httpOnly-cookie |
| Документы | загрузка `multipart/form-data`, хранение в MinIO |

Контракты эндпоинтов — `../backend/src/api/routers/`, коллекция Postman —
`../postman/`.

## Запуск

Сборки пока нет. После добавления стека здесь появятся команды; корневой
`make front` уже зарезервирован под них.
